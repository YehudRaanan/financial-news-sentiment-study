# Public release checklist

- [ ] Select and add a software license.
- [ ] Confirm the author name and citation metadata.
- [ ] Confirm permission for all report text and visual elements.
- [ ] Run `uv run ruff check .`.
- [ ] Run `uv run pytest`.
- [ ] Rebuild the example in a fresh clone.
- [ ] Scan tracked files for credentials, local paths, logs, article text, and provider responses.
- [ ] Confirm that Git tracks no research dataset or temporary review file.
- [ ] Change repository visibility only after this review.
